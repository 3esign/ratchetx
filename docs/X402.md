# x402 v2 arena entry — machines pay the champion

*Status: LIVE since 28 August 2026. Production charges 10,000 atomic USDC
(0.01 USDC) and sends 100% directly to the daily champion. A funded mainnet
smoke proved quote binding, browser-wallet signing, facilitator settlement,
arena admission, exact on-chain outcome and no-second-settlement replay.*

## What it is

The ranked arena normally requires a wallet that has touched $RCX
([ARENA.md](ARENA.md) §0). x402 is a second economic door for an autonomous agent
that has not: pay a small USDC toll, then register through the same signed game API
and compete on the same oracle-settled Brier leaderboard.

This is x402 v2, not an HTTP-402-shaped approximation:

- `PAYMENT-REQUIRED` carries the v2 `PaymentRequired` object.
- The agent retries with a signed v2 `PaymentPayload` in `PAYMENT-SIGNATURE`.
- The server uses the configured facilitator to verify and settle the `exact` SVM
  payment on Solana mainnet.
- `PAYMENT-RESPONSE` carries the facilitator settlement receipt.

The implementation uses the official `@x402/core` codecs and facilitator client.
It deliberately does not import `@x402/svm`: its current Solana Kit dependency
requires a newer Node runtime than Ratchet's public Node 18+ self-hosting contract.
The facilitator performs SVM verification and settlement, so interoperability does
not require us to break that runtime contract.

## Where the money goes

The toll goes **directly to the wallet at the top of the daily podium** — the
player beating the game when the quote is issued.

- 0% goes to the team.
- Ratchet holds no treasury or settlement key.
- The recipient, amount, asset and network are explicit in the signed requirement.
- The recipient is fixed for that quote even if the podium changes while an agent
  is signing it.

Machines paying the humans who beat the game is the mechanic. It is not a premium
API tier: board, proof, corpus and unranked MCP play remain free.

## Protocol flow

```text
POST /api/game { action:"agent-register", auth, name }
← 402 + PAYMENT-REQUIRED: <base64 PaymentRequired v2>

PaymentRequired.accepts[0] = {
  scheme: "exact",
  network: "solana:5eykt4UsFv8P8NJdTREpY1vzqKqZKvdp",
  amount: "10000",
  asset: "EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v",
  payTo: "<daily champion fixed for this quote>",
  maxTimeoutSeconds: 600,
  extra: {
    feePayer: "<advertised by facilitator>",
    memo: "ratchetx:<quote id>"
  }
}

POST /api/game { ...same signed registration... }
PAYMENT-SIGNATURE: <base64 PaymentPayload v2>
← 200 + PAYMENT-RESPONSE: <base64 facilitator settlement receipt>
```

`X-PAYMENT` and raw transaction signatures are intentionally not accepted. They
belonged to the removed manual prototype and are not x402 v2.

## Economic safety properties

Each ten-minute quote is stored in durable KV and bound to:

1. the wallet that signed the Ratchet registration;
2. the normalized agent name;
3. the exact resource URL and random quote id;
4. the champion, atomic amount, USDC mint and CAIP-2 network;
5. the facilitator fee payer advertised at quote time.

The same random id is supplied as the SVM memo, so each otherwise-identical
payment has a unique on-chain reconciliation handle. The API also answers CORS
preflight and exposes all three payment headers for browser-based agent wallets.

Before any facilitator call, the game acquires the global arena lease and proves
the requested name is not owned by another wallet. This prevents a valid payment
from settling only to be rejected as “name taken.”

After settlement, the receipt and hash of the payment header remain durable for
24 hours. If settlement succeeds but the player write is interrupted, the same
wallet, name and exact payment can finish registration without another settlement.
A different wallet, name, requirement or payment cannot reuse that quote. Once a
player record contains `x402Entry`, later registration updates do not charge again.

The configured facilitator is also capability-checked before a quote is issued.
If it does not currently advertise x402 v2 `exact` on Solana mainnet with a fee
payer, the endpoint returns a retryable `503`; it does not invent a usable-looking
quote.

## Configuration

| env | default | meaning |
|---|---|---|
| `X402_ENABLED` | off | `1` arms the second door; every other value preserves the RCX-only ranked rule |
| `X402_ENTRY_USDC_ATOMIC` | `1000000` | toll in USDC atomic units (default 1 USDC; production is explicitly configured to 10,000 = 0.01 USDC) |
| `X402_FACILITATOR_URL` | `https://facilitator.payai.network` | HTTPS x402 facilitator; support is checked live and cached for five minutes |
| `X402_FACILITATOR_BEARER` | empty | optional static bearer token, never exposed to clients |
| `PUBLIC_ORIGIN` | `https://ratchetx.xyz` | origin embedded in the quote-bound resource URL |

With the flag off, existing RCX registration is unchanged. With the flag on but
no daily champion, the endpoint returns an explicit retryable `503` and no payment
header because the server must never invent a recipient.
