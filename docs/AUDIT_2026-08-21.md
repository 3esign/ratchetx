## Critical/high findings fixed

1. **Raw JavaScript appended after `</html>`.** The screenshot was genuine: 2,423 bytes of
   mixed UTF-16/UTF-8 script and 146 NUL bytes were rendered as footer text. The corrupt
   tail and stale duplicate file were removed; the intended listener now lives in the real
   script. The unsupported “reclaim rent” control was removed.
2. **Settlement source substitution.** A shot sealed on Pyth could previously settle on a
   Coinbase fallback print. New shots pin `oracleSrc`; a missing same-source crossing update
   voids/refunds instead of changing referee.
3. **Concurrent wallet spending.** Two simultaneous requests could both spend one balance.
   Per-wallet distributed locks now admit exactly one. Challenge acceptance also locks both
   wallets, releases a failed acceptance gate, and writes both players plus the offer list in
   one Redis Lua transaction.
4. **Event-log retention race.** Shared chunk blobs could lose a concurrent event. Every log
   index now has a permanent single-writer `g:log:e:<index>` record; snapshots and THE RECORD
   batch-read these authoritative entries and repair legacy chunk gaps.
5. **Mirror confirmation trusted too little.** Confirmation now validates signer, program,
   discriminator, nonce, commitment, feed, expiry, kind, threshold, and one reward per shot.
   Mirroring remains disabled unless an explicit program ID and RPC are configured.
6. **Burn amount parsing.** Verification now uses raw integer token amounts plus decimals and
   refuses unreadable balances rather than treating them as zero.
7. **Stored/browser XSS.** Server/RPC errors no longer enter `innerHTML`; agent-controlled
   name/blurb and wallet displays are escaped.
8. **Runtime supply-chain scripts.** The Jupiter embed and three CDN fallbacks were removed.
   The exact Solana Web3 browser bundle is vendored locally; CSP restricts executable code to
   the site origin. Jupiter opens as an external `noopener` link.
9. **Base58 leading-zero bug.** The shared decoder added one byte to keys beginning with `1`,
   rejecting valid Solana keys. It now round-trips leading-zero keys correctly.

## Known residual risks

### Launch blockers

1. **Not deployed yet.** Production still reports h50. Deploy h51, then run the complete
   smoke test against the deployment before moving the domain.
2. **Domain not connected.** At audit time, apex and `www` returned no DNS records. Add both
   in Vercel, use the exact records Vercel supplies, redirect one canonical hostname, and wait
   for managed TLS before publishing the URL.
3. **On-chain v1 not release-built or mainnet-deployed.** This repository contains source,
   not a reproducible Anchor/Cargo project with deployment artifacts. Keep mirror controls
   disabled until a separate program audit, reproducible build, devnet test, mainnet program
   ID, and client migration are complete.
4. **Regulatory review.** Token burns plus token payouts tied to oracle-price outcomes can be
   treated as gambling, a prediction product, or a derivative depending on jurisdiction.
   Obtain qualified counsel and implement the resulting age/jurisdiction controls before
   paying for broad promotion. Do not market credits or RCX as earnings.

### Medium engineering debt

- A few single-player actions still update the player JSON record and shared analytical/pot
  counters as separate durable operations. Player locks prevent double-spending and queues
  protect real reload credits, but a Redis failure between those writes can temporarily skew
  aggregate pot/stat counters. Before high traffic, move all stake/refund/yield transitions
  into one server-side transaction or an idempotent journal with reconciliation.
- The CSP still permits inline script/style because the application is a single HTML file.
  External execution is blocked, but a future hardening pass should split assets and use
  hashes/nonces to remove `'unsafe-inline'`.
- The real social/X URL is intentionally absent. Add the actual handle before buying Enhanced
  Token Info; never submit a placeholder.
